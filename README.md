# 梦见马克思 · Dream of Marx

一个独立开发的交互式叙事学习原型：梦中的机械马克思通过一轮轮问题，帮助用户探索个人条件、工作、战线、成果和力量积累之间的关系。

## 当前版本：v0.1（2026-11-04）

- 梦境故事与 Avatar 涂鸦／图片上传
- 机械导师即时反馈、分支问答、齿轮音效
- 初步建议与简化的互动全景图
- 单页 HTML，完全在浏览器运行；无需 AI API、账号或后端

### 运行

打开仓库根目录的 `index.html` 即可。若配置了 GitHub Pages，则可从公开网页访问。

### GitHub Pages 设置

Repository → **Settings → Pages** → Source 选择 **Deploy from a branch** → Branch 选 **main**、文件夹选 **/(root)** → Save。

如果使用 GitHub Free，GitHub Pages 要求仓库为 Public。仓库公开后，源代码与提交记录会对所有人可见，操作前请确认不含私密资料。

### 开发方向

先独立完善 Avatar、机械人偶动画和音效、对话脚本与条件规则、互动全景图和移动端体验。暂不进行任何第三方网站联动。

### 隐私与说明

当前原型不向服务器发送问答或图片，头像仅用于本地页面体验。历史人物的所有台词均为虚构艺术演绎，不是真实历史引文。本作品用于理论学习与情景探索，不提供确定性现实行动建议。

目前尚未确定长期软件许可证，后续公开发布前再明确。
