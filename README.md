# 梦见马克思 · Dream of Marx

**v0.2 · 第一场梦 — 2026-11-04**

一场奇怪而温柔的粘土人偶剧：你在梦中遇见一位坚信自己就是马克思的导师。他在舞台上发问，你转动黄铜选择器回答；最后，一座关于革命实践条件与关系的全景图缓缓展开。

**[在线体验 GitHub Pages](https://koi1917.github.io/dream-of-marx/)**

## v0.2 已实现

- **实体质感舞台**：粘土动画风格的马克思人偶形象、丝绒布景、黄铜道具
- **旋转式机械选择器 + 选项铜牌**：转动、卡扣、多选和分类浏览；附可关闭的机械音效
- **Avatar 简化**：极简线条小人，可在触屏涂鸦，支持颜色、撤销、重画；取消了图片上传
- **自由身份介绍**：“你叫……”“你是一名……”；对话可照读，不尝试理解用户的身份含义
- **社会环境优先**：先讨论社会环境及公共参与条件，再讨论同伴、时间、能力和兴趣
- **扩充测试数据**：7轮问答、21个能力选项、18类工作卡
- **结果与全景图**：按条件给出可探索的工作，点击查看工作—战线—成果—力量积累关系，并切换假想环境条件

## 核心创作原则

> **让机械的笨拙留在表演中，让理论的严谨留在逻辑里。**

马克思人偶不知道自己是人偶。他会认真地说“你是一名一只会写诗的猫”，却不意识到这种固定语法有任何滑稽之处。所有对白均为虚构艺术演绎，不是历史引文。

这是**理论学习和情境探索工具**，不试图精确预测现实中的个人或集体应该采取何种行动。环境问题仅讨论概括条件，**不要求提供真实组织、地点或他人身份**。

## 运行与部署

当前版本依然是 **零构建、零后端、零 AI API** 的单页静态网页。将仓库下载后，打开 `index.html` 即可运行；图像位于 `assets/marx-puppet.webp`。

GitHub Pages 从 `main` 分支的仓库根目录部署，不需要配置密钥、数据库或模型 API。

浏览器不上传 Avatar、姓名、自由身份或问答答案。本原型没有账号和服务端个人资料存储，刷新后会清除当前会话。可以关闭音效；动效尊重系统的“减少动态效果”偏好。

## 目前的限制

- 仍是 **v0.2 原型**，不是完成版：人物主要使用静态实物质感素材与轻动画，尚未实现逐帧定格人偶表演
- 答案与工作关系是教学用的初步规则，未达到完整组织学模型的覆盖度
- 旋转铜牌在小屏幕、辅助功能与大量选项时仍有优化空间
- 暂时不与其他网站联动
